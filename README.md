Symptomtracker – Frontend

Dieses Projekt ist das Frontend unseres Symptomtrackers.

Milestone 2

Wir haben mit Vue.js eine Webanwendung erstellt.

In der eigenen Komponente `SymptomList.vue` werden
drei Beispiel-Symptome mithilfe von `v-for` angezeigt:

- Kopfschmerzen
- Augenzucken
- Knieschmerzen

Technologien

- Vue.js
- JavaScript
- HTML
